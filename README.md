# CRUD en Java

Aplicación de consola desarrollada en Java para gestionar productos utilizando las operaciones básicas de un CRUD.

## Funcionalidades

- **Crear:** añadir productos con nombre y precio.
- **Leer:** mostrar todos los productos.
- **Actualizar:** modificar el precio de un producto.
- **Eliminar:** borrar productos mediante su ID.
- **Validaciones:** controlar entradas incorrectas mediante excepciones.

## Tecnologías utilizadas

- Java
- ArrayList
- Scanner
- Programación orientada a objetos (POO)
- Manejo de excepciones (try-catch)

## Objetivo

Practicar los fundamentos de Java, las operaciones CRUD y el manejo de excepciones mediante una aplicación sencilla por consola.

**Nota:** Los productos se almacenan en memoria y se pierden al cerrar el programa.
